BEN BAZZITE — HYPRLAND SHORTCUTS

APPS
Super + D                 App launcher
Super + Return            Terminal
Super + E                 Files
Super + A                 Quick controls
Super + N                 Notifications
Super + Comma             Shell settings
Super + F1                This shortcut guide

WINDOWS
Super + Q                 Close window
Super + F                 Fullscreen
Super + Space             Toggle floating
Super + P                 Toggle pseudotile
Super + Tab               Cycle windows
Super + Arrow             Move/swap active window
Super + Shift + Arrow     Focus window in that direction
Super + Left Mouse        Drag active window
Super + Right Mouse       Resize active window

WORKSPACES
Super + 1…9               Switch workspace
Super + Shift + 1…9       Send window to workspace
Super + Mouse Wheel       Cycle workspaces
Super + S                 Toggle scratchpad
Super + Shift + S         Send window to scratchpad

SESSION
Super + L                 Lock
Super + Shift + E         Power/session menu

SCREENSHOTS
Print                     Select a region
Shift + Print             Capture all outputs

MEDIA
Volume/Brightness keys    Adjust volume or brightness
Play/Next/Previous keys   Control media playback

DANKBAR
Click the launcher        Apps, files, and search
Click the clock           Calendar and agenda
Click audio/network/BT    Ben OS quick controls
Click notifications       Notification center
Click power               Power/session menu
